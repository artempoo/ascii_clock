# ASCII strange clock

Программа выводит текущее время в terminal в ASCII формате.

## Компиляция

у вас должен быть установлен meson
[mesonbuild](https://mesonbuild.com/Quick-guide.html)

### Сборка meson зависимостей

```sh make build```

### Сборка и Запуск проекта

```sh make```

### Запуск проекта

```sh make run```
